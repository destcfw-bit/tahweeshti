# تحويشتي V7

تطبيق مالي شخصي عربي/PWA بتصميم أخضر زمردي + ذهبي، عملة الدينار الأردني، وحساب مشترك برمز PIN من 4 أرقام فقط.

## أهم الميزات
- 💚 إلي / 🔴 عليّ / 📈 إيرادات / 📉 مصاريف / 💳 دفعات جزئية.
- 👥 دفتر أشخاص مع كشف حساب، ملاحظات، تثبيت، مشاركة واتساب، وطباعة PDF عبر نافذة الطباعة.
- ⚖️ تسوية تلقائية لصافي الديون المتبادلة مع الشخص.
- 🎯 أهداف تحويش، مساهمات، مراحل متعددة، Streak وإنجازات.
- 💰 ميزانية شهرية وحدود حسب التصنيف.
- 🏦 محافظ متعددة: كاش، بنك، CliQ، محفظة، وتوفير + تحويل بين المحافظ.
- 📆 أقساط مع تتبع التقدم والقسط القادم.
- 🔁 حركات متكررة تلقائيًا: يومي/أسبوعي/شهري/سنوي.
- 🏷️ تصنيفات ووسوم وطرق دفع ورقم مرجعي لكل حركة.
- 📅 رزنامة مالية + فلترة حسب السنة والتصنيف والمحفظة والحالة.
- 📊 تحليلات 6 أشهر، توقع نهاية الشهر، أعلى التصنيفات وتنبيهات الصرف غير الطبيعي.
- 💡 بطاقة «قراري اليوم» + مؤشر صحة مالية.
- 🎙️ إضافة بالصوت + ✨ إضافة ذكية من جملة عربية.
- 📸 إيصالات وصور + OCR اختياري لاستخراج مبلغ محتمل من الصورة.
- 🔔 تنبيهات استحقاقات عند فتح التطبيق (حسب سماح المتصفح).
- 👁️ إخفاء الأرقام + Light/Dark + وضع عرض فقط.
- 🔒 قفل تلقائي + تغيير PIN + رمز إدارة اختياري للحذف النهائي.
- 🗑️ سلة محذوفات 30 يوم + ↩️ تراجع + سجل تغييرات Audit Log.
- 💾 نسخ احتياطي/استرجاع + نسخة طوارئ.
- 📱 PWA قابل للتثبيت + اختصارات سريعة من أيقونة التطبيق.

## البنية
- `index.html` الواجهة.
- `styles.css` الهوية والأنيميشن والاستجابة للموبايل.
- `app.js` منطق التطبيق والمزامنة والميزات.
- `config.js` إعداد الاتصال بـ Supabase.
- `manifest.webmanifest` و `service-worker.js` لتثبيت التطبيق.
- `backend/schema_v7_features.sql` توسعة قاعدة البيانات.
- `supabase/functions/tahweeshti-api/index.ts` Backend / PIN / المزامنة.

## الأمان
لا تضع `SUPABASE_SERVICE_ROLE_KEY` داخل ملفات الواجهة أو GitHub. المفتاح السري يبقى داخل Supabase Edge Function فقط.

## النشر
المستودع مربوط مع Railway. بعد تحديث ملفات `main` سيبدأ Railway إعادة النشر تلقائيًا.

## V7.4 — حسابات متعددة برمز رباعي
- زر «إنشاء حساب جديد» ظاهر على شاشة الدخول دائمًا.
- كل حساب يختار PIN من 4 أرقام فقط.
- منع تكرار الـPIN على مستوى كل الحسابات من داخل الـBackend وقاعدة البيانات.
- كل حساب معزول بالكامل: حركات، دفعات، أهداف، محافظ، اشتراكات، إعدادات، سلة محذوفات وسجل تدقيق.
- نفس PIN يفتح نفس الحساب من أي جهاز.
- الحساب القديم والبيانات القديمة يتم ترحيلهم تلقائيًا للحساب الأصلي.
